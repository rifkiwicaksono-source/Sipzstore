# Sipzstore

Frontend-only web app for a digital printing business.

## Features
- Landing page for a digital printing company
- Product pricing section with instant estimate
- Order form for custom quote requests
- Responsive design for desktop and mobile
- No backend required

## Run locally
Option 1: Open `index.html` directly in your browser.

Option 2: Run a local web server from this folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project files
- `index.html` — main app structure
- `styles.css` — styling and responsive layout
- `script.js` — pricing calculator and form actions

## Purpose
This project is a frontend prototype for a digital printing storefront and quote request app.
